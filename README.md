# 🌍 Portfolio Virtuel 3D — Tour de l'Afrique de Bamako
### **Moussa Kouyaté** — Développeur Front-End & Full-Stack (Bamako, Mali)

Un portfolio virtuel immersif en 3D développé en **HTML5**, **CSS3**, **JavaScript**, **Three.js** et **GSAP**, modélisant fidèlement le monument prestigieux de **La Tour de l'Afrique** à Bamako.

---

## 🏛️ Structure par Étage

* 🌟 **Niveau 5 (Sommet)** : Profil, Vision, Langues & Atouts.
* ⚡ **Niveau 4 (Belvédère)** : Compétences Tech (React, Angular, JavaScript, Java JEE, Python, MySQL, etc.).
* 🚀 **Niveau 3 (Fût central)** : Projets Réalisés (App Quiz JEE, Club IKADEV, Clones UX/UI, etc.).
* 🎓 **Niveau 2 (Base)** : Diplômes (Licence & DUT Informatique de Gestion ESCT, Bac TSE, Certifications ODC).
* 📍 **Niveau 1 (Esplanade)** : Contact direct & Réseaux.
